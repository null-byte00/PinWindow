# PinWindow

Закрепляет любое окно поверх всех остальных — видео поверх игры, гайд поверх редактора.

![Windows](https://img.shields.io/badge/Windows-10%2F11-blue) ![.NET](https://img.shields.io/badge/.NET-8-purple)

## Хоткеи

- **`Ctrl+Alt+P`** — сфокусированное окно: закрепить поверх всех / открепить
- **`Ctrl+Alt+G`** — «сквозной клик»: клики проходят сквозь закреплённое окно в игру (смотришь видео, играешь дальше)

## Трей

Список закреплённых окон (клик — открепить), «Открепить все», автозагрузка, выход.

## Технически

`SetWindowPos(HWND_TOPMOST)` + `WS_EX_TRANSPARENT|WS_EX_LAYERED` для сквозного клика. Single-file exe, живёт в трее, ~3 МБ RAM.
